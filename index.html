Veracity AI

2025 – Present

AI-Powered Fake News Detection & Digital Wellbeing Platform

Veracity AI is an intelligent AI-powered platform designed to combat online misinformation while promoting healthier digital habits. The application combines Fake News Detection using Google's Gemini AI with Digital Wellbeing analytics to help users verify online information and understand their smartphone usage patterns.

  • Developed an AI-powered fake news detection system using Google Gemini API capable of analysing news articles, URLs and social media posts with confidence scores and detailed AI explanations.
  • Integrated an AI chatbot to verify user claims, explain misinformation and provide educational responses using advanced prompt engineering.
  • Designed a Digital Wellbeing module capable of analysing daily, weekly and monthly smartphone screen time, social media usage, unlock count and application statistics.
  • Built an AI Recommendation Engine that suggests healthier digital habits, productivity improvements and personalised screen-time reduction strategies.
  • Created interactive dashboards showing app-wise usage, productivity score, weekly reports, monthly analytics, peak usage hours and Digital Balance Score.
  • Implemented secure authentication, user history, analytics reports and REST APIs using Django REST Framework.
  • Android companion application uses UsageStatsManager API for collecting screen-time statistics with user permission.

I believe technology creates the greatest impact when it solves real-world problems and improves everyday life.

I'm Divyanshu Yadav, currently pursuing my Master of Computer Applications (MCA) at Pondicherry University. I am passionate about Artificial Intelligence, Full Stack Development, Data Analytics, and building intelligent software that delivers meaningful solutions.

My interests focus on Large Language Models (LLMs), Machine Learning, Natural Language Processing, Cloud Computing, and modern web technologies.
